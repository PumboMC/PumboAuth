== A1 console: pumboauth help
  PumboAuth 0.1.3-beta · Admin   /pumboauth /pa
    /pumboauth reload                                  Reload the config and messages
    /pumboauth stats                                   Logins, accounts and players
    /pumboauth forceregister <nick> <password>         Create an account
    /pumboauth forcechangepassword <nick> <password>   Set a password
    /pumboauth unregister <nick>                       Remove an account
    /pumboauth forcelogin <nick>                       Log in a waiting player
    /pumboauth forcepremium <nick>                     Make an account premium
    /pumboauth forceoffline <nick>                     Make an account normal
    /pumboauth reset2fa <nick>                         Turn off two-factor login
    /pumboauth unblock <ip|nick>                       Clear failed logins
    /pumboauth logout <nick>                           Remove the sessions of an account
    /pumboauth import authme <file>                    Import accounts from AuthMe
    /pumboauth version                                 Version and platform
